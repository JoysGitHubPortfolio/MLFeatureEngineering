> Write a Python utility module named `bootstrapper.py` under `src/utils/` exposing a single function, `cluster_bootstrap`, that produces a confidence interval and p-value for a regression coefficient estimated on panel data.
> The personas dataset is a person-month panel: 306 people in my analysis base contribute 1,324 rows. A person's months are not independent evidence, so analytic standard errors that treat rows as observations are falsely narrow. The bootstrap must therefore resample whole **people**, never individual rows, so that the effective sample size stays honest at the number of people. Implement it as follows:
> * **Model-Agnostic Interface:** Accept a `fit` callable that takes an array of row indices and returns one number (the coefficient), a `groups` array of person IDs aligned to the rows, `n_boot`, and a seeded `np.random.Generator`. The function must know nothing about the regression itself, so the same utility can bootstrap any estimator.
> * **Cluster Resampling:** Precompute the row indices belonging to each person once. On each of the `n_boot` iterations, draw as many people as exist in the data, uniformly and with replacement, concatenate their row indices, and re-run `fit` on that set. A person drawn twice contributes all of their months twice; roughly a third of people are left out of any given draw. Every resample is the same size as the real sample: the number of iterations controls how precisely the sampling distribution is traced, not how much evidence there is.
> * **Percentile Interval:** Return the 2.5th and 97.5th percentiles of the bootstrap draws as the 95% confidence interval.
> * **Bootstrap p-value:** Return a two-sided p-value against a null of zero, computed as twice the smaller tail share of draws `<= 0` or `>= 0`, capped at 1. This feeds the Benjamini-Hochberg correction applied across the eight platforms in `feature_analysis.py`.
>
>
> Pass the generator in rather than creating it inside the function, so the caller seeds once (`SEED = 42`) and every run reproduces the same intervals on a reviewer's laptop. The person-level fixed effects in my design survive resampling unchanged, because each person's rows are demeaned against their own average before bootstrapping, so a person drawn twice simply behaves as two identical clusters. Note in the docstring that the bootstrap quantifies sampling noise only: it cannot correct measurement bias such as the iOS meter missing Google Search, which is why the analysis pairs it with device-split robustness checks.
