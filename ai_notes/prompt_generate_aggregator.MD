> Write a Python utility module named `aggregator.py` under `src/utils/` that centralises the feature-scoping and dispersion logic currently duplicated between `feature_cleaning.py` and `feature_selection.py`.
> Both scripts independently re-derive the numeric feature space and re-apply the support threshold, so the two have already drifted — the cleaning script ranks CV over `all_numeric` (leaking the `year`/`month` metadata columns into the plot shortlist) while the selection script correctly excludes them. Collapse this into a single source of truth exposing a `META_COLS` constant and the following two pure functions:
> * **Scope Isolation (`feature_numeric_cols`):** Accept a DataFrame, a `min_support_pct` float defaulting to `0.0`, and an overridable `meta_cols` list. Select numeric dtypes, use `Index.difference()` to drop metadata, then return the subset of columns whose non-zero support `(df[cols] > 0).mean()` meets the threshold. The `0.0` default must make the support filter a no-op, so a single function serves both the unfiltered 347-column scope and the filtered scope without a second entry point.
> * **Normalised Dispersion (`active_stats`):** Accept a DataFrame and a column subset, and return a DataFrame of `non_zero_pct`, `mean_all`, `mean_active`, `std_active` and `cv_active`. Mask inactive rows once with `.where(df[cols] > 0)` and let pandas' NaN-skipping aggregations do the rest — do **not** use `.apply()` with a per-column `lambda x: x[x > 0]`, which forces a Python-level loop over every column and makes the zero-row guard clauses necessary in the first place. Derive `cv_active` as `std_active / mean_active.abs()` to keep the coefficient of variation positive under sign flips.
>
>
> On NaN semantics: where a column has no active rows (or only one, for the standard deviation), the statistic is genuinely not estimable, so propagate `NaN` rather than coercing to `0`. A zero mean would otherwise act as a denominator and emit a fabricated CV. Keep both functions free of I/O and printing so they stay unit-testable, annotate the signatures with type hints, and accept `list[str] | pd.Index` for the column subset so callers can pass a list comprehension or the `Index` returned by `feature_numeric_cols` interchangeably.
